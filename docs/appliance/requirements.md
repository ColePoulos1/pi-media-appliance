# Product intent and release requirements

A friend flashes a microSD card, plugs a Raspberry Pi 5 into a TV, joins Wi-Fi and links a personal TorBox account. They can search for a movie or show and watch it with their existing TV remote. A viewer with a NAS or USB drive uses exactly the same search results, Play button, favorites and Continue Watching. The current home setup combines Kodi, Fen Light+, CoCoScrapers, Prowlarr on a home server and TorBox. The appliance should remove the setup burden and keep the playback quality of that working system.

## Viewer journey

| Area | Required result |
| --- | --- |
| First boot | Start at a single TV-friendly wizard. Detect Ethernet, otherwise allow Wi-Fi selection with an on-screen keyboard. Present TorBox's verification code and QR/link for phone authorization, with manual key entry available. Allow local-only use. Finish at Home. Make one-time pairing of an iOS remote optional. |
| Interface | Home offers Search, Favorites and Continue Watching. One card per movie or episode opens a detail view with Play/Resume. Use one fixed layout with readable type, visible focus and predictable Back. All required actions work using arrows, OK and Back, including on TVs with few transport keys. |
| Library | Optionally add a local folder or read-only SMB share with credentials. Scan asynchronously and persist the index. Merge confident matches by provider-qualified movie or episode ID. Prefer explicit IDs/NFO metadata to filename matches. Keep unmatched files accessible and correctable. A sleeping or temporarily unavailable NAS retains its entries and history. |
| Discovery | Get titles, seasons, episodes and artwork from TMDB. Search the cached local catalog while online discovery runs. Local files remain available offline. Release discovery uses a built-in adapter plus optional Prowlarr results. Combine and deduplicate candidates across sources. Prowlarr is a pilot integration and optional for friends. |
| Play | A playable matching downloaded copy starts before any remote discovery or resolution. If the local copies fail, check available remote candidates and use TorBox for a file-specific stream. Default Play is a single action. Automatic retries, language choices, quality profiles and manual recovery follow the [selection spec](stream-selection.md). An uncached download cannot be advertised as instant play. |
| State | A favorite or resume point identifies a title/episode for a viewer. Store file identity separately and resolve temporary URLs on demand. A remote-to-SMB or SMB-to-remote change retains the bookmark. Reopen the same title from Search, Favorites, Continue Watching or the iOS remote to reach the same decision. |
| Playback quality | Keep Kodi VideoPlayer, Pi hardware decoding where supported, refresh-rate matching, HDR on compatible chains, multichannel/HD audio where supported, stereo fallback, and audio/subtitle track controls. Re-evaluate the actual TV/audio chain after an HDMI move. |
| Remotes | TV remote controls the Pi through HDMI-CEC. Verify focus, navigation, Back and on-screen playback controls. The scope ends at inbound TV remote input. Preserve Official Kodi Remote for iOS with authenticated LAN access, discovery, text input, Now Playing and playback control. Verify any exposed library/favorite items open the appliance's title path. |
| Settings | Show Network, TorBox account, optional Media folders, default audio/subtitle language, and Balanced / High Quality / Data Saver. Default language prompts separately for movies, TV and anime. Keep overrides for device detection, data limits, and optional Prowlarr under advanced settings. Avoid asking about formats or providers during normal setup. |
| Delivery | Produce a versioned Pi 5 flash image and a matching update. Preserve library/settings on upgrade. Test failed-update recovery and how to restore the previous working system and compatible data. Use a project-controlled update channel for the derivative. |

## What to simplify

Keep Kodi's GUI/input, VideoPlayer, AudioEngine, hardware integration, subtitles, library/bookmark mechanisms, CEC, SMB client and remote API. Replace the stock home, setup flow, release browsing and add-on installation experience. Implement new product logic in C++. The Kodi route permits a fixed bundled skin and necessary internal runtime dependencies. Audit their footprint and call sites before removing them, especially LibreELEC's settings service for networking and updates. Seek a smaller image and lower memory through measured package changes. Removing a menu only changes what the viewer sees.

General add-on repositories, skin switching, music, games, pictures, PVR and a general-purpose file manager are outside the viewer interface. Retain accessibility and subtitle rendering resources that active users need. Later work includes portable backup/restore and a separate live-sports experience. Learned ranking, additional boards and smartphone apps are also outside the first release.

## Decisions that need evidence

- **Default release source.** Prototype with a configured Prowlarr instance. Before friends try it, choose a source that can ship with the image, works with only household TorBox credentials and is permitted to distribute. Compare movie and episode coverage against the current CoCoScrapers setup. A documented HTTP stream adapter returning file hashes/indexes is a candidate. The two-input setup promise depends on a functioning default provider.
- **TMDB access.** Register the product, follow attribution and applicable use terms, and decide credential delivery for a publicly downloadable image. Treat credentials embedded in an image as extractable. A viewer should never need their own developer registration.
- **Budgets.** Record compressed and installed size, cold-boot time to usable Home, idle/playback RAM, CPU, dropped frames and times to first frame for local and remote. Compare with stock LibreELEC on the same Pi and card. The only initial numeric target is p95 below 50 ms for 200 already-parsed candidates. Use measurements to set the remaining budgets.
- **Distribution.** Choose product branding before releasing an image. Preserve upstream notices and applicable source obligations. The inspected Fen Light+ snapshot lacked an identified license for copying its implementation or art. Record permission or use an original implementation.
