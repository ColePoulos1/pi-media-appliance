### Identifier and member evidence

Keep the TMDB movie or episode ID as the appliance title key. Use TMDB's movie and series `external_ids` to obtain the IMDb ID used in Stremio's movie and episode addressing. Episode requests use the IMDb series ID plus season and episode coordinates. The separate TMDB episode external-ID endpoint can provide corroborating metadata. A missing IMDb mapping is a distinct failure for an IMDb-only adapter. [Movie external IDs](https://developer.themoviedb.org/reference/movie-external-ids) · [Series external IDs](https://developer.themoviedb.org/reference/tv-series-external-ids) · [Episode external IDs](https://developer.themoviedb.org/reference/tv-episode-external-ids) · [Stremio stream request](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/requests/defineStreamHandler.md)

Use a discovery hash to check the viewer's own TorBox account from the Pi. Treat provider file indices and filenames as evidence to reconcile against the actual TorBox member path, identifier and size. Stremio's missing-index rule selects the largest file, which can select the wrong episode in a pack. BitSearch's search size describes the whole release. Prefer resolver member bytes for ranking and carry unknown size when no exact member size is available. Ignore URL-only, status and non-torrent entries in the discovery path. Preserve valid results if another adapter times out, is throttled or returns malformed data. Reject an ambiguous member and keep uncached additions at zero. These are comparison requirements, pending the live run. [Stremio stream response](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/responses/stream.md) · [TorBox torrent API](https://api-docs.torbox.app/) · [Selection contract](stream-selection.md)

## TMDB application registration

**Local development key verified.** The owner supplied an API key from a dedicated disposable TMDB account with no other services linked. The public source fork uses a Git-ignored workstation `.env` with the entry `TMDB_API_KEY=<your-key>`. Kodi reads this key from its process environment for development. Export it before launching Kodi. A workstation request to `/3/configuration` returned HTTP 200 on 21 November 2026.

**Owner confirmation, 22 November 2026.** The owner confirmed that the TMDB key may be distributed in the private friends image. The official application-auth guide uses the API Read Access Token in an `Authorization: Bearer` header for v3 and v4. That flow authenticates catalog reads without asking each viewer to sign in to TMDB. [TMDB FAQ](https://developer.themoviedb.org/docs/faq) · [Application authentication](https://developer.themoviedb.org/docs/authentication-application) · [API settings](https://www.themoviedb.org/settings/api)

Sections 1 and 2 of the API terms make the non-commercial license non-transferable and non-sublicensable. They reserve termination rights, limit caching of TMDB information to six months, and require purging cached TMDB content on termination. The linked site terms also restrict sharing the account, profile or password. Inject the application read token during private packaging from outside Git, keep it out of URLs and logs, and support replacement in a subsequent build. Apply the cache rules to TMDB-derived data and artwork when implementing catalog persistence. [API Terms of Use](https://www.themoviedb.org/api-terms-of-use) · [Site Terms of Use](https://www.themoviedb.org/terms-of-use)

Use an approved TMDB logo at lower prominence than the appliance mark in About or Credits. Use the fuller notice from API Terms §3. “This product uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.” Check those assets and fresh-image search without viewer registration after obtaining the credential. TMDB publishes no SLA. Its approximate upper limit can change, and clients should respect HTTP 429.
